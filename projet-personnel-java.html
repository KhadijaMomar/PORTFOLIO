Projet de Gestion de Personnel

Présentation du projet

Cette application est une solution de gestion du personnel permettant d’administrer les employés au sein de différentes ligues. Elle est conçue en ligne de commande (CLI) et suit une architecture 3-tiers. Actuellement, l’application est mono-utilisateur, mais l’objectif est de la rendre multi-utilisateurs en intégrant une base de données pour gérer les accès et les permissions des différents acteurs. Chaque ligue doit être administrée par un employé désigné comme administrateur, qui est chargé de gérer les employés de sa ligue. Un super-administrateur dispose de droits étendus pour gérer tous les employés et administrateurs des différentes ligues.

Objectifs et améliorations prévues

Rendre l’application multi-utilisateurs

L’application doit passer d’un mode mono-utilisateur à un mode multi-utilisateurs grâce à une base de données relationnelle (MySQL). Chaque utilisateur aura un compte avec des droits spécifiques en fonction de son rôle.

Mettre en place des niveaux d’habilitation

Trois niveaux d’accès doivent être définis pour garantir une gestion sécurisée :

Employé de ligue

  • Peut ouvrir l’application et consulter la liste des employés comme un annuaire.
  • Ne possède aucun droit d’écriture sur les données.

Administrateur de ligue

  • Désigné parmi les employés d’une ligue.
  • Dispose de droits d’écriture pour gérer les employés de sa propre ligue.
  • Peut ajouter, modifier et supprimer les employés de sa ligue via une application bureau.

Super-administrateur

  • Gère toutes les ligues et tous les employés.
  • Peut ajouter, modifier ou supprimer les administrateurs des ligues.
  • Utilise une application en ligne de commande pour administrer le système.

Ajouter des dates d’arrivée et de départ pour chaque employé

  • Chaque employé doit avoir une date d’arrivée et une date de départ dans l’entreprise.
  • Ces informations permettent de suivre l’historique des employés et d’identifier ceux qui sont toujours en activité.

Permettre la gestion des administrateurs

  • Un super-administrateur doit pouvoir changer l’administrateur d’une ligue en sélectionnant un employé existant.
  • Cette modification doit respecter les droits d’accès définis pour chaque rôle

Fonctionnalités principales

Gestion des Ligues

  • Afficher toutes les ligues.
  • Ajouter une nouvelle ligue.
  • Sélectionner, renommer ou supprimer une ligue.

Gestion des Employés

  • Afficher la liste des employés d’une ligue.
  • Ajouter un employé(Nom et prénom Adresse e-mail Mot de passe Date d’arrivée et date de départ)
  • Selectionner un employé(modifier ou supprimer l' employé)

Gestion des Administrateurs

  • Afficher l’administrateur d’une ligue.
  • Changer l’administrateur à partir d’une liste d’employés.

Sécurité et exceptions gérées

  • DroitsInsuffisants : si un administrateur tente d’accéder à une autre ligue.
  • ImpossibleDeSupprimerRoot : si l’on tente de supprimer le super-administrateur.
  • SauvegardeImpossible : si une erreur empêche l’enregistrement.

Architecture technique

  • Interface utilisateur : CLI pour le super-admin, application bureau pour les administrateurs.
  • Couche métier : Gère la logique de gestion du personnel.
  • Couche de persistance : Base de données MySQL.
